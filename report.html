2 Project Profile

2.1 Project Definition

The Cybersecurity Awareness Training Website is an interactive, full-stack web application designed to educate users on critical cybersecurity threats. It provides a structured learning environment with comprehensive topics, progress tracking, knowledge assessments via quizzes, and a practical phishing simulator to ensure users can identify and mitigate real-world cyber risks.

2.2 Project Description

The system is built on a robust Python Flask backend using a modular Blueprint architecture, integrated with a relational database (PostgreSQL/SQLite) via SQLAlchemy ORM. The frontend utilizes HTML5, Jinja2 templating, and Bootstrap 5 for a responsive and intuitive user experience. The platform supports role-based access control, allowing learners to track their quiz scores and topic progress, while administrators can manage the curriculum, questions, and view platform-wide analytics.

2.3 Existing System

The conventional approach to cybersecurity awareness relies on static documents, generic video seminars, or disorganized online articles that suffer from:

  • Lack of Interactivity: Users passively consume information without practical assessment.
  • No Progress Tracking: Organizations cannot measure if a user has actually learned the material.
  • Absence of Practical Simulation: Users read about phishing but are rarely tested on simulated examples in a safe environment.
  • Fragmented Management: Difficult to update content and track scores without a centralized dashboard.

2.4 Problem Statement

With the rapid increase in social engineering, phishing, and data breaches, average internet users and employees lack a unified, engaging platform to learn and test their cybersecurity hygiene. There is a critical need for an accessible training ecosystem that bridges the gap between theoretical security concepts and practical threat identification.

2.5 Need for the New System

  • Unified Educational Platform: Replaces scattered resources with a structured, step-by-step curriculum.
  • Measurable Knowledge: Enforces learning through dynamic quizzes and retains score histories.
  • Practical Phishing Simulation: Trains users to visually identify malicious links and emails.
  • Admin Governance: Allows instructors/admins to continually update question banks and monitor user performance.

2.6 Proposed System & Key Features

  • Multi-Role Portals: Tailored dashboards for standard Users (Learners) and Administrators.
  • Curriculum & Progress Engine: 8 structured cybersecurity topics with completion tracking.
  • Dynamic Quiz System: Automated scoring, answer explanations, and percentage calculations across 40 questions.
  • Phishing Awareness Simulator: Interactive module to test users against common phishing tactics.
  • Password Strength Analyzer: Client-side entropy calculator and crack time estimator.
  • Admin Control Panel: Interface to add/edit quiz questions and monitor platform metrics.
  • Secure Authentication: Password hashing (Werkzeug) and session management (Flask-Login).

2.7 Scope

The project provides an end-to-end full-stack web application with responsive layouts, supporting user registration, learning modules, assessments, and an administrative backend, engineered for both local SQLite execution and cloud-native PostgreSQL deployment.

2.8 Expected Outcomes

A highly accessible training platform that curtails user vulnerability to cyber threats, provides measurable metrics on security awareness, and offers a scalable foundation for organizational security training.

2.9 Tools & Technology Used

  • Frontend: HTML5, CSS3, Bootstrap 5, Jinja2 Templates, JavaScript (ES6+)
  • Backend: Python 3.11/3.12, Flask, Flask-Login, Werkzeug
  • Database & ORM: PostgreSQL 16 (Neon Serverless) / SQLite 3, SQLAlchemy, Flask-SQLAlchemy
  • Environment & Hosting: python-dotenv, Gunicorn, Render Cloud Platform
Part II
Analysis & Design

3 Requirement Analysis

3.1 Feasibility Study

Technical Feasibility: The architecture utilizes proven, lightweight frameworks. Flask provides high flexibility for web routing, while SQLAlchemy ensures database abstraction (easily switching between SQLite for dev and PostgreSQL for prod). Bootstrap guarantees UI responsiveness without heavy frontend frameworks.

Operational Feasibility: The platform addresses the clear need for security training. The intuitive dashboard ensures that non-technical users can navigate topics and quizzes with zero friction.

Economic Feasibility: The system is built entirely on open-source technologies (Python, Flask, PostgreSQL, Bootstrap), requiring zero licensing fees, making it highly cost-effective to deploy on platforms like Render or Railway.

3.2 Users of the System

  • Learner (User): Registers, reads topic content, attempts quizzes, participates in phishing simulations, and tracks personal scores.
  • Administrator: Manages the question bank, oversees topic content, and monitors user engagement and scores.

3.3 Functional Requirements

  1. User Authentication & RBAC: Secure registration and login using hashed passwords and session management.
  2. Topic Navigation: Users must be able to view a list of topics and read detailed content for each.
  3. Quiz Engine: The system must present multiple-choice questions linked to specific topics and calculate scores instantly.
  4. Progress Tracking: The system must record when a user completes a topic and log their quiz scores permanently.
  5. Admin Dashboard: Admins must have the ability to create, read, update, and delete (CRUD) quiz questions.
  6. Phishing Simulator: An interactive module demonstrating safe vs. unsafe digital interactions.

3.4 Non-Functional Requirements

  • Security: Passwords must be hashed. Routes must be protected by session guards. Admin routes must check for boolean flags.
  • Usability: The interface must be mobile-responsive and visually engaging to encourage learning.
  • Reliability: Relational ACID guarantees provided by the underlying SQL database.

Part III
Implementation & Testing

5 Implementation

5.1 Coding Convention

  • Modular Blueprints: The application is divided into logical modules (auth.py, main.py, quiz.py, admin.py) using Flask Blueprints to keep routing clean and maintainable.
  • Environment Configuration: Sensitive credentials and database URIs are loaded via .env files using python-dotenv, adhering to 12-Factor App principles.
  • ORM Data Management: Direct SQL queries are avoided. All database interactions utilize SQLAlchemy objects for security and cross-database compatibility.

5.2 Security Measures

  • Authentication: Sessions are managed securely using Flask-Login.
  • Password Storage: Passwords are cryptographically hashed using werkzeug.security.generate_password_hash (pbkdf2:sha256). Plaintext passwords are never stored.
  • Access Control: is_admin boolean flags ensure standard users cannot access the /admin routes.
  • Injection Prevention: SQLAlchemy ORM inherently parameterizes queries, preventing SQL Injection attacks.

6 Testing

6.1 Test Strategy

Testing focuses on route authorization, database relational integrity (e.g., ensuring a score is tied to the correct user and topic), and accurate calculation of quiz percentages.
